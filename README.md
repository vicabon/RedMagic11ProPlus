## 1. 第一時間「黃金 5 步」安全防護與應急處置

紅魔 11 Pro+ 具備特殊電競硬體，碎裂後切忌按一般直板手機對待！

> [!CAUTION]
> **透明版核心致命風險：**
> 紅魔 11 Pro+ 內部置有高達 **24,000 RPM 的高速渦輪散熱風扇** 與 **AquaCore 脈動微泵液冷循環管路**。
> 後蓋碎裂時產生的細小玻璃渣，極易被主動風道吸入卡死風扇軸承，或因按壓刺破脆弱的超薄微循環水冷管造成冷卻液外洩短路！

1. **立即用寬版透明膠帶順平封印：**
   * 使用文具封箱寬膠帶完整包覆破裂背板，撫平氣泡。
   * **關鍵目的：** 防止碎屑劃傷雙手，並徹底阻絕細小玻璃微粒滲透進內部風道或微泵機構。
2. **手動關閉散熱風扇或立即關機：**
   * 若屏幕正常顯示，下滑控制中心手動關閉「散熱風扇」；在「魔姬 / 遊戲空間」中關閉風扇自動起停。
   * 若非緊急使用，建議**直接長按電源鍵關機**，避免震動引起碎玻璃移位。
3. **嚴禁接觸任何水分與液體：**
   * 玻璃一旦碎裂，手機原有的氣密防水性能已完全喪失。請遠離水源，切勿用水沖洗背板髒污。
4. **檢查並保護相機光學鏡面：**
   * 紅魔 11 Pro+ 採一體化純平背板，檢查後鏡頭覆蓋玻璃有無受損，避免手指重壓摩擦到底層感光元件與 OIS 雲台。
5. **換上全包覆厚手機殼：**
   * 在進行維修前，套上原廠附贈或市售高包覆性的防摔軟殼，避免攜帶碰撞導致裂紋進一步碎成細渣。

## 2. 專業級拆卸後蓋方式與必備工具

由於紅魔採用無凸起一體封膠及緊湊內部模組，拆卸時需格外小心。

### 🛠️ 拆卸工具清單
* **恆溫加熱墊 / 溫控熱風槍：** 溫度設定在 **80°C ~ 85°C**，加熱 3~5 分鐘使原廠密封背膠軟化。（**嚴禁超過 90°C**，以免高溫使電池膨脹或軟化水冷微循環管）。
* **超薄拆機金屬開屏片 (0.08mm)：** 僅用於最初切入原廠背膠的第一道微小縫隙。
* **高韌性塑料翹片 / 撥片：** 進入縫隙後全程使用塑料翹片切膠，避免金屬工具割斷天線或排線。
* **強力工業吸盤：** 吸附於玻璃後蓋較完整區域，提供垂直向上的穩定拉力。
* **無水高純度酒精 (IPA 99.7%) + 針筒：** 微量點注於翹片前端以溶解殘膠。（**禁止大面積噴灑**，否則會溶入相機鏡片起霧或進入風道）。
* **ESD 防靜電手套、護目鏡與防靜電鑷子：** 避免碎玻璃迸濺入眼，清除殘膠及微小碎屑。
* **專用預切成型防水背膠貼 / B-7000 膠水：** 組裝新後蓋時必備。

### 📋 拆解操作核心要點
1. **吸盤拉出縫隙：** 加熱完成後，在背蓋下半段施以吸盤拉力，拉出約 0.5mm 微縫。
2. **嚴格限制插入深度：** 塑料翹片插入機身邊緣**不得超過 2.5 ~ 3mm**！
3. **避開致命走線區：**
   * **頂部相機與中央區：** 設有 RGB 信仰燈帶、風扇燈效排線與 NFC/天線線圈。
   * **右側風道格柵：** 為獨立風道濾網模組，切忌硬撬。
4. **徹底清理中框：** 掀開後蓋後，先用鑷子清理碎屑，再用解膠劑清潔中框膠槽，中框若殘留碎玻璃將導致新蓋壓合時直接受力破裂。
